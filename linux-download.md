# Download Linux Mint

## Overview

Download the Linux Mint Cinnamon ISO image for creating a bootable USB installer.

## 1. Open the Official Website

Visit the official Linux Mint download page:

https://linuxmint.com/download.php

## 2. Select the Edition

Select:

* **Edition:** Cinnamon
* **Architecture:** 64-bit (x86_64)

Cinnamon provides a desktop environment with a familiar Windows-like layout.

## 3. Download the ISO

Choose a download mirror and download the ISO file.

The file will have a name similar to:

```text
linuxmint-22.3-cinnamon-64bit.iso
```

The exact filename may vary depending on the release.

## 4. Verify the Download

Linux Mint provides checksums to verify the integrity of the downloaded ISO.

Compare the downloaded file's SHA256 checksum against the official checksum published by Linux Mint.
